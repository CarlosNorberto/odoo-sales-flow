Odoo Sales Flow

Cliente Node.js que ejecuta el flujo de ventas completo en Odoo vía JSON-RPC, controlado desde una CLI interactiva en terminal.

CLI interactiva

app.js
$ node ./app.js
 
? ¿Qué querés ejecutar?
── Pasos individuales ──────────────
1. Autenticar
2. Crear venta
3. Crear y confirmar venta
4. Crear, confirmar y validar salida de productos
5. Crear, confirmar y crear factura
6. Confirmar factura (Flujo completo)
───────────────────────────────────
Salir

Qué ejecuta cada opción

# Descripción Estado final en Odoo
1 Autenticar — obtiene el uid de sesión uid
2 Crear venta — genera sale.order draft
3 Crear y confirmar venta sale
4 + Obtener picking y validar salida de productos done
5 + Crear factura desde la venta draft
6 + Confirmar factura — flujo completo posted

Operaciones (operations.js)

# Función Modelo / Método RPC
1 createSaleOrder() sale.order → create
2 confirmSaleOrder(saleId) sale.order → action_confirm
3 getPickingIdForSale(saleId) stock.picking → search_read
4 validateAndCreateBackorderStockPicking(pickingId) stock.picking → button_validate
5 createInvoiceFromSale(saleId) sale.order → _create_invoices
6 confirmInvoice(invoiceId) account.move → action_post

Variables de entorno

.env
ODOO_URL http://localhost:8069 URL base de la instancia
ODOO_DB nombre_de_tu_db Nombre de la base de datos
ODOO_USERNAME admin Usuario con permisos de venta
ODOO_PASSWORD •••••••• Contraseña o API Key

Parámetros de la venta

Los datos de la orden se configuran en params.json. Los campos partner_id, product_id y tax_id usan XML IDs de Odoo, resueltos a IDs numéricos antes de crear la venta.

params.json
          {
              "order": {
                  "partner_id": "base.res_partner_12",
                  "date_order": "2026-03-01",
                  "order_line": [
                      {
                          "product_id": "sale.product_product_4e",
                          "product_uom_qty": 1,
                          "price_unit": 100.0,
                          "tax_id": [
                              "account.1_sale_tax_template",
                              "account.1_purchase_tax_template"
                          ]
                      },
                      {
                          "product_id": "product.desk_organizer",
                          "product_uom_qty": 2,
                          "price_unit": 50.0,
                          "tax_id": [
                              "account.1_sale_tax_template",
                              "account.1_purchase_tax_template"
                          ]
                      }
                  ]
              }
          }

Los XML IDs se encuentran en Odoo con modo desarrollador activo:
Ajustes → Técnico → Secuencias e identificadores → Identificadores externos

Manejo de errores

Los errores técnicos (red, credenciales, Odoo) muestran el mensaje y terminan con exit 1. Los errores de autenticación vuelven al menú sin interrumpir la sesión.

Autenticación fallida
Credenciales incorrectas o DB errónea
Vuelve al menú · verificar .env
Access Denied
Sin permisos sobre el modelo
Sale con exit 1 · asignar grupos en Odoo
ECONNREFUSED
Odoo no disponible o URL incorrecta
Sale con exit 1 · verificar ODOO_URL
